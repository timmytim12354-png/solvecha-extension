Solvecha Auto-Captcha

Auto-solve hCaptcha and Cloudflare Turnstile with your own solvecha.net account. Every solve is billed to your key — there is no shared key in this extension.

API key

Keys are minted on solvecha.net after linking your Discord account — paste the key and press Check & save.

  1. Create an account at solvecha.net (email/password or Discord).
  2. Link your Discord account — this is the verification step. Without it no API key can be created.
  3. Create a key on the dashboard, or DM !api to the Solvecha bot on Discord to have a fresh key sent to you.
  4. Paste the key above. Usage (monthly quota, total solves) is tracked to that account.

Auto-solve

When on, the extension detects hCaptcha and Cloudflare Turnstile widgets (checkbox, invisible, and challenge pop-ups) and solves them automatically.

Paused sites

Captchas on these sites are never auto-solved. Matches the domain and all its subdomains.

    How the key stays safe

    Any secret baked into a Chrome extension can be extracted — an extension is just a zip anyone can unpack. So this extension holds no shared key at all:

    1. Each user needs their own solvecha.net account with a linked Discord account.
    2. The API key is minted per account and is stored only in your browser's chrome.storage.local.
    3. Solves are sent straight to solvecha.net with your key as Bearer auth — usage lands on your account's quota, and no one else can use your allowance.
    4. Stealing the extension's source gives an attacker nothing: there is no key in it.
