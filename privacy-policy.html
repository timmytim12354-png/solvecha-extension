Solvecha — Privacy Policy

Last updated: August 27, 2026

Solvecha ("we", "us") operates the Solvecha hCaptcha Solving API and the Solvecha Chrome Extension. This privacy policy explains what data the extension collects, how it is used, and your choices.

Data We Collect

  • API Key: Your Solvecha API key is stored locally in your browser via chrome.storage.local. It is never sent anywhere except to the Solvecha API endpoint (solvecha.net) to authenticate solve requests.
  • Extension Settings: Your on/off toggle preference is stored locally in chrome.storage.local.

How We Use Your Data

  • The API key is used solely to authenticate requests to the Solvecha solving service.
  • The extension communicates only with solvecha.net and the target page you are visiting.
  • No data is sold, shared with third parties, or used for advertising.

What We Do NOT Collect

  • We do not collect browsing history, personal information, location data, or health/financial information.
  • We do not track your activity across websites.
  • We do not use analytics or tracking pixels.

Data Storage & Security

  • All data is stored locally on your device. Nothing is transmitted to external servers except the solve request sent to the Solvecha API.
  • API keys are stored as-is in local extension storage. They can be deleted at any time by removing the extension or clearing extension storage.

Third-Party Services

  • Solvecha API (solvecha.net): The extension sends the target sitekey and page URL to the Solvecha API to obtain a solved hCaptcha token. No personal data is transmitted.

Children's Privacy

The extension is not directed at children under 13 and does not knowingly collect data from children.

Changes to This Policy

We may update this policy from time to time. Changes will be reflected on this page with an updated date.
